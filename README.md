# Green API Test Task

Веб-приложение в стиле **Messenger Web** для работы с [Green API](https://green-api.com/) — сервисом отправки и приёма сообщений через WhatsApp, Telegram и другие мессенджеры.

## 🚀 Демо

[Открыть демо](https://maddlogg.github.io/green-api-test-task/)

## Возможности

- **Отправка текстовых сообщений** через Green API по номеру телефона
- **Приём входящих сообщений** через long polling (`receiveNotification`)
- **Логика прочитанных/непрочитанных** сообщений (счётчик в сайдбаре)
- **Тёмная и светлая темы** с сохранением выбора
- **Мобильная адаптация** — полноэкранный чат на мобильных устройствах

## Как пользоваться

### 1. Авторизация

При первом запуске откроется экран входа. Введите:

- **idInstance** — идентификатор инстанса Green API
- **apiTokenInstance** — токен доступа к инстансу

> ⚠️ Параметры сохраняются **только в памяти** (не в localStorage). При перезагрузке страницы их нужно ввести заново.

### 2. Создание чата

1. Нажмите кнопку **«Новый чат»** в шапке сайдбара
2. Введите **номер телефона** в международном формате (например, `+7 900 000-00-00`)
3. Нажмите «Создать»

Чат появится в начале списка и сразу откроется.

### 3. Отправка сообщений

- Введите текст в поле ввода внизу чата
- Нажмите **Enter** или кнопку отправки
- Статусы сообщений:
  - ✓ — отправляется
  - ✓✓ — доставлено
  - «Не отправлено» — ошибка (наведите курсор для деталей)

### 4. Приём входящих

- Приложение автоматически опрашивает Green API каждые 30 секунд
- Входящие сообщения появляются в чате, если чат с этим номером уже создан
- Если чат закрыт — счётчик непрочитанных увеличивается (синий бейдж в сайдбаре)
- При открытии чата счётчик сбрасывается

### 5. Переключение темы

Нажмите иконку **Sun/Moon** в шапке сайдбара. Выбор сохраняется в localStorage.

## API Green API

Приложение использует следующие эндпоинты:

| Метод  | Эндпоинт                                                 | Назначение                           |
| ------ | -------------------------------------------------------- | ------------------------------------ |
| POST   | `/waInstance{id}/sendMessage/{token}`                    | Отправка сообщения                   |
| POST   | `/waInstance{id}/setSettings/{token}`                    | Настройка вебхуков                   |
| GET    | `/waInstance{id}/receiveNotification/{token}`            | Получение уведомлений (long polling) |
| DELETE | `/waInstance{id}/deleteNotification/{token}/{receiptId}` | Удаление уведомления из очереди      |

## Формат chatId

Номер телефона нормализуется в формат Green API:

```
+7 900 000-00-00  →  79000000000@c.us
8 900 000-00-00   →  79000000000@c.us
```

- Убираются все нецифровые символы
- `8` в начале заменяется на `7`
- Добавляется суффикс `@c.us`

## Ограничения

- Поддерживаются **только текстовые** сообщения (фото, документы и т.д. игнорируются)
- Чаты создаются **только вручную** (автосоздание из входящих отключено)
- Никнеймы не поддерживаются — только номера телефонов
- Параметры авторизации не сохраняются между сессиями
